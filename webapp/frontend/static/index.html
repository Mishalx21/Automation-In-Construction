Building code compliance checking

Catch code problems before you build.

Every building has to follow thousands of safety rules — how wide a door is, how high a ceiling sits, how thick a slab needs to be. Checking them by hand takes an expert days, and one missed rule can mean tearing finished work out again. Upload your building model and get a straight answer: what breaks the rules, by how much, and exactly where.

Two things you can do. Hover or tap a card to see how it works.

1Upload your buildingThe 3D model your design software already produces.
2Everything gets measuredEach door, stair, room, beam and slab, one by one.
3Measurements meet the codeEvery figure is held against the limit the rule sets.
4You get the verdictPass or fail, the exact numbers, and the part at fault.

Nothing is guessed. Every answer comes from measuring your actual model, so the same file always gives the same result — and you can see the figure behind each one.

  • pass — checked, nothing wrong
  • fail — problems found, with the numbers
  • unclear — your file is missing what this rule needs, so it never guesses a pass
  • not applicable — this rule does not apply to your building
1Read the designEvery door, stair, wall and room in your model is listed.
2Pick a rule to breakChoose which requirement the new version should fail.
3Make the changeThe model is edited only where it has to be.
4Prove it brokeThe result is measured again to confirm the rule now fails.

All or nothing. Each change is made in a sealed, separate run and then measured again on its own. If the change cannot be made and confirmed, you get nothing back — never a half-finished file.

  • Checked first — nothing may touch your other files
  • Run in isolation — sealed off, with a time limit
  • Measured again — only the change you asked for may appear
